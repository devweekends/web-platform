We are proud to celebrate Talha Amjad, a Dev Weekends fellow, on being selected for **LFX Mentorship 2026 Term 3** under the **Cloud Native Computing Foundation (CNCF)**.

![Talha Amjad, selected mentee in LFX Mentorship 2026](/images/lfx-2026-talha-amjad.jpg)

## What he will be working on

Talha will be contributing to [Volcano](https://volcano.sh/), the CNCF batch scheduling system built on Kubernetes for AI, machine learning and high-performance workloads. His project is **Generic xPU Topology-Aware Scheduling**: teaching the scheduler to understand how GPUs, NPUs and other accelerators are physically connected, so that jobs land on hardware that talks to itself fast. It is the kind of infrastructure problem that every large AI training cluster runs into, and the code he writes will run in production clusters around the world.

| | |
|---|---|
| Program | LFX Mentorship 2026, Term 3 (September to November) |
| Foundation | Cloud Native Computing Foundation (CNCF) |
| Project | Volcano, Generic xPU Topology-Aware Scheduling |
| Areas | Kubernetes, AI infrastructure, cloud native, open source |

CNCF accepted 59 mentorship projects for Term 3. Each one is a paid, mentored, three-month engagement on a real open source codebase, with a maintainer reviewing your work. Getting one is a fantastic opportunity to contribute to production-grade open source and grow alongside the global community.
